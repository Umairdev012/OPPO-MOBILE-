# 📱 OPPO F3S Android Mobile Simulator

A fully interactive Android mobile simulator built using HTML, CSS, and JavaScript. This project recreates a realistic smartphone experience inside the browser, featuring a lock screen, home screen, app launcher, notification panel, calculator, phone dialer, messages, camera, gallery, browser, and settings interface.

## 🚀 Features

- 🔐 Interactive Lock Screen
- 🏠 Modern Android Home Screen
- 📞 Phone Dialer & Contacts
- 💬 Messaging Application
- 📷 Camera Simulation
- 🖼️ Gallery App
- 🌐 Browser Interface
- ⚙️ Settings Panel
- 🔢 Fully Functional Calculator
- 🔔 Notification Center
- 📡 Quick Settings Toggle
- ⏰ Live Time & Date Updates
- 📱 Responsive Mobile UI Design
- 🎨 Modern Gradients & Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ▶️ How to Run

1. Download or clone the project.
2. Open `oppo-f3s-android.html` in any modern web browser.
3. Unlock the device and explore the apps.

## 🎯 Purpose

This project was created to demonstrate advanced front-end development skills by simulating a complete Android smartphone interface using only HTML, CSS, and JavaScript without any external frameworks.
